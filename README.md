# The Flame Probe

Interactive simulation for A Level Physics: using a flame probe to measure the potential between charged parallel plates, plus a candle flame between the plates.

Live site: https://awm11.github.io/flame-probe/

## Run locally

```bash
npm install
npm run dev
```

Pushing to `main` builds the site with Vite and deploys it to GitHub Pages (see `.github/workflows/deploy.yml`).
